# Argument Stress-Test Web App - Instructions

The web version of the Argument Stress-Test Tool is now running!

## How to Access:

1. **Open your web browser** (Chrome, Firefox, Safari, etc.)

2. **Go to this address:**  
   http://localhost:5000

3. **Using the web app:**
   - Enter your position or argument in the text area on the home page
   - Click "Begin Stress-Test"
   - Work through each of the six stages:
     1. Steel-man
     2. Verify Evidence
     3. Three Strongest Objections
     4. Demolition Attempt
     5. Rebuild
     6. The Call
   - For each stage, read the description and prompt, then type your reflections in the text area
   - Click "Continue to Next Stage" when you're ready to proceed
   - After completing all stages, review your journey and insights

## Features:
- ✅ Fully interactive web interface
- ✅ Saves your notes for each stage
- ✅ Progress tracking throughout the process
- ✅ Mobile-responsive design
- ✅ Complete review of your stress-test journey at the end
- ✅ Ability to start over or reset at any time

## Technical Details:
- Built with Python Flask framework
- Runs locally on your machine (no internet required after startup)
- All data stays in your browser session (not stored permanently)
- Accessible at http://localhost:5000

## To Stop the App:
When you're finished using the app, you can stop it by pressing `Ctrl+C` in the terminal where it's running.

Enjoy using the Argument Stress-Test Tool to strengthen your thinking and arguments!
